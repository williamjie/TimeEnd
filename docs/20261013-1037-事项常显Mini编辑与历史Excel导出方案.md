# TimeEnd 事项常显、Mini 编辑与历史 Excel 导出方案

## 1. 背景与目标

上一期已支持：专注中通过「事项」按钮弹层编辑、结束预填、历史可改、按天日期筛选。

用户反馈与新诉求：

1. **专注中事项常显**：计时旁直接看到当前事项，不必每次点开按钮才知道在做什么
2. **历史 Excel 导出**：记录可导出为 Excel，便于复盘与归档
3. **最小化窗口也要显示/修改事项**：小窗常态使用时同样能看、能改

> 本文档仅供审核，确认后再按 Superpowers TDD 实施。

---

## 2. 现状摘要

| 能力 | 现状 |
|------|------|
| 主窗事项 | 专注中右侧「事项」按钮 + 弹层；**界面上不常显文案** |
| Mini 窗 | 宽约 234px；计时 / 状态 / 开始暂停停止 / 记录设置；**无事项展示与编辑** |
| 草稿同步 | 主进程 `focusMatter`；IPC `get/set-current-focus-matter`、`focus-matter-visibility` |
| 历史 | 弹窗列表可编辑 `inputContent`；**无导出** |
| 依赖 | 无 Excel 相关库 |

相关文件：`index.html` / `main.js`（renderer）、`mini.html` / `mini-renderer.js`、`main.js`（main）、`sessionStore.js`。

## 3. 需求理解（请核对）

| # | 诉求 | 方案理解 |
|---|------|----------|
| A | 专注中旁边显示事项 | 计时区域旁/下增加一行「当前事项」摘要，专注中（含暂停）可见 |
| B | 减少点击 | 摘要常显；点击摘要或「编辑」仍打开现有弹层 |
| C | 历史 Excel 导出 | 记录弹窗增加「导出」；导出当前筛选范围内的专注（及可选休息）为 Excel 文件 |
| D | Mini 显示与修改事项 | 小窗专注中显示事项摘要；可打开编辑（小弹层或简易输入）并写回同一草稿 |

**默认假设（可改）：**

1. 常显为**单行截断摘要**（主窗 16 / Mini 10）；**悬停看全文**；完整编辑仍用弹层；编辑入口仅「编辑」/✎
2. 导出格式优先 **`.xlsx`**；若审核希望零依赖，可改为带 BOM 的 **`.csv`（Excel 可直接打开）**
3. 导出范围 = **当前记录筛选结果**（按天/周/月已筛出的数据），不只导出全部历史
4. Mini 与主窗共用主进程草稿，任一处修改另一处可见
5. 非专注状态：主窗/Mini 均不显示事项摘要
6. 常显不得挤占大号倒计时；放在计时/状态**下方**

## 4. 功能方案

### 4.1 主窗：事项常显

**布局原则（避免抢时间显示）**

- **时间与状态保持视觉中心**，常显事项不得挤压、遮挡大号倒计时
- 编辑入口保留，但文案要短：原「事项」改为 **「编辑」**（或仅 ✎ 图标）；**禁止**在计时旁堆长标签
- 常显只展示**截断摘要**；完整内容通过 **鼠标悬停 tooltip** 查看，避免界面文案过多

**布局建议**

```
┌─────────────────────────────────────┐
│  TimeEnd                     [编辑] │  ← 短文案入口，勿加长说明
│           24:30                     │  ← 倒计时不受挤占
│          专注中                     │
│  事项：写方案文档……                 │  ← 单行截断；hover 出全文
└─────────────────────────────────────┘
```

**显示长度限制（强制）**

| 区域 | 摘要最大字数（默认） | 超出时 |
|------|----------------------|--------|
| 主窗常显 | **16 字**（可配置常量，实现时统一） | 截断 + `…` |
| Mini 摘要 | **10 字** | 截断 + `…` |

- 空草稿：显示短占位「未填写」（计入长度策略时可整段替换，不叠加长前缀）
- 前缀「事项：」可选；若担心更挤，主窗可用更淡/更小字号的一行，**不加第二行说明文案**

**悬停看全文**

- 常显元素设置 `title`（原生 tooltip）为**完整草稿原文**（未截断）
- 仅当全文与摘要不同（发生截断）或需要确认原文时依赖悬停；空占位可不设或设「点击编辑」
- Mini 同样：悬停摘要显示全文

**行为**

| 状态 | 常显行 | 编辑按钮 |
|------|--------|----------|
| 准备就绪 / 休息 | 隐藏 | 隐藏 |
| 专注中 / 暂停 | 显示截断摘要；hover 见全文 | 显示「编辑」/✎ |
| 点击摘要或编辑 | 打开现有事项弹层 | — |

**同步**

- 弹层保存 / 关闭自动保存后，立即刷新常显文案与 `title`
- 主进程广播 `focus-matter-updated`（内容变更）时主窗与 Mini 一并刷新

### 4.2 Mini：显示与修改事项

**布局建议（小窗宽度有限）**

```
┌──────────────────┐
│      24:30       │
│      专注中      │
│ 写方案文档……  ✎ │  ← 截断摘要；鼠标移上去显示全文；点击编辑
│ [开始][暂停][停止]│
└──────────────────┘
```

**最小化悬停看全文（必须）**

- 进入最小化小窗后，专注中事项仍只显示**短摘要**（≤10 字），避免撑破小窗
- **鼠标移到事项摘要（或事项行）上时，必须能看到事项全文**（原生 `title` tooltip，或等价悬停提示）
- 全文 = 主进程当前草稿完整原文，与主窗悬停一致；截断与否都建议设置 `title`，保证小窗也能一瞥全文而不必先点开编辑
- 空占位「未填写」时：悬停可提示「点击编辑事项」或可不设全文

**编辑方式（推荐）**

- 点击摘要或 ✎：在 Mini 内弹出**轻量浮层**（textarea + 保存/关闭），关闭时自动保存草稿（与主窗一致）
- 不强制还原主窗，避免打断「贴边小窗」使用习惯

**备选（不推荐作默认）**：点编辑先 `restore-from-mini` 再开主窗弹层——步骤多，违背「少点击」。

**窗口尺寸**

- 显示事项行时，Mini 高度略增（约 +18~28px）；非专注时恢复原高度
- 用现有 `setSize` / 内容驱动高度，避免裁切
- 悬停 tooltip 为系统浮层，不占用 Mini 布局高度

### 4.3 历史 Excel 导出

**入口**

- 记录弹窗标题栏或汇总行旁增加按钮：「导出 Excel」

**导出内容（推荐）**

| 列 | 说明 |
|----|------|
| 类型 | 专注 / 休息 |
| 开始时间 | 本地可读时间 |
| 结束时间 | 本地可读时间 |
| 时长（分钟） | durationMinutes |
| 事项 | 仅专注有；休息为空 |

- 行顺序与当前列表一致（结束时间倒序）
- 文件名建议：`TimeEnd-记录-{筛选说明}-{时间戳}.xlsx`  
  例：`TimeEnd-记录-2026-10-13-20261013-1036.xlsx`

**技术选型（请拍板）**

| 方案 | 优点 | 缺点 |
|------|------|------|
| **A. 纯 CSV + UTF-8 BOM**（推荐默认若求稳） | 零依赖；Excel 中文正常；实现快 | 扩展名 `.csv`，非原生 xlsx |
| **B. 生成真正 `.xlsx`**（如 `exceljs` / `sheetjs`） | 符合「Excel 导出」字面 | 增加依赖与打包体积 |

**推荐**：先采用 **A（CSV，文件名仍可用「导出 Excel」文案，或按钮写「导出为 Excel(CSV)」）**；若你明确要 `.xlsx`，则选 B。

**保存交互**

- 使用 Electron `dialog.showSaveDialog` 让用户选路径；取消则不写文件

## 5. 技术方案

### 5.1 数据流

```
主窗常显 / Mini 摘要  ←── focus-matter-updated / get-current-focus-matter
         │
         ▼
   主进程 focusMatter 草稿
         │
         ├── 结束打断窗预填（已有）
         └── set-current-focus-matter（主窗弹层 / Mini 浮层）
```

### 5.2 IPC 增补

| Channel | 方向 | 说明 |
|---------|------|------|
| `focus-matter-updated` | M→R（主窗+Mini） | `{ content }` 草稿变更广播（set 时发出） |
| `export-sessions` | R→M→R | 传入当前筛选 `{ type, value }` 或已加载会话；主进程写文件并 reply 结果 |
| （复用）`get/set-current-focus-matter` | 已有 | Mini 编辑走同一套 |

### 5.3 模块拆分（便于 TDD）

| 模块 | 职责 |
|------|------|
| `focusMatterDisplay.js`（纯函数） | 摘要截断、`formatMatterSummary(text, maxLen)`、空占位文案 |
| `sessionsExport.js`（纯函数） | 会话 → CSV 行 / Sheet 行；文件名生成 |
| Mini / 主窗 UI | 接线与样式 |
| `main.js` | 广播、`dialog` 保存、调用 export |

### 5.4 涉及改动文件（预估）

| 文件 | 改动 |
|------|------|
| `src/renderer/index.html` + `styles/main.css` | 常显行；导出按钮 |
| `src/renderer/scripts/main.js` | 常显刷新；导出触发 |
| `src/renderer/mini.html` + `mini-renderer.js` | 摘要行 + 编辑浮层；高度 |
| `src/main/main.js` | 广播；export IPC；Mini 尺寸 |
| `src/main/sessionsExport.js`（新） | 导出纯逻辑 |
| `src/renderer/scripts/focusMatterDisplay.js`（新） | 摘要纯逻辑 |
| `test/*.test.js` | 摘要截断、导出行列与文件名 |

## 6. 交互与边界

1. **硬限制**：主窗摘要默认最多 **16 字**，Mini **10 字**；超出截断加 `…`，禁止用多行或放大字号挤占倒计时
2. **悬停全文**：截断后 `title` 为完整原文；未截断时可与展示一致或省略 tooltip
3. 草稿为空：短占位「未填写」，仍可点击编辑；不写长提示句
4. 编辑按钮仅用「编辑」或 ✎，不附加说明性长文案
5. Mini 编辑与主窗弹层同时打开时：后保存覆盖先保存；以主进程最终值为准
6. 导出无数据：提示「当前筛选无记录可导出」，不生成空文件（默认**不生成**）
7. 导出不包含未结束的进行中草稿（仅已落库会话）
8. XSS：常显用 textContent；`title` 用属性赋值；列表导出为文件不经 HTML
